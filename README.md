# 豆瓣爬虫项目
## 📋 功能说明
1. 爬取豆瓣Top250榜单电影名称、封面图片；
2. 批量下载电影封面图，自动处理文件名非法字符；
3. 抓取电影短评文本；
4. 使用jieba对评论分词，过滤停用词；
5. 根据分词结果生成评论词云图，可视化高频关键词。

## 🛠运行环境
- Python 3.10(64-bit)
- 第三方库：`requests`、`jieba`、`wordcloud`、`lxml`、`beautifulsoup4`

安装依赖命令：
```bash
pip install requests jieba wordcloud beautifulsoup4 lxml
```
使用方法:下载压缩包后,将压缩包移动至vscode，下载第三方库后即可运行

## ⚠️ 注意事项
1.本项目中的代码路径和浏览器的headers值均需自己添加，文件中有操作提示。
2. 豆瓣有反爬机制，建议设置请求间隔 `time.sleep(1~2)`，不要高频大量请求，避免IP封禁。
3. 本项目**仅用于课程学习，禁止用于商业用途**，遵守网站robots协议。
4. 网络请求失败时，尝试添加请求头 User-Agent 模拟浏览器访问。
5. Windows系统注意文件路径写法，避免转义字符报错；程序会自动创建保存文件夹，也可手动预先建立。
6. 豆瓣部分图片源为`.webp`格式，若强制保存为`.jpg`会出现图片无法打开问题，代码内已做格式适配处理。
7. 词云生成如出现中文方框乱码，需要在代码中指定中文字体路径。

## ❓ 常见问题
1. 图片下载成功但是无法打开？
> 原因：原始图片是webp格式，后缀命名错误；解决方案：代码识别链接后缀，区分保存 .jpg / .webp。
2. 词云中文显示方框乱码？
> wordcloud默认不支持中文，需要加载本地中文字体文件。
3. 请求返回403禁止访问？
> 缺少User-Agent请求头，或者请求频率过快，增加请求头与延时。
